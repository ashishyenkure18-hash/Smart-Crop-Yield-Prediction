
# Smart Crop Yield Prediction Using Deep Neural Networks

## Project Overview

Smart Crop Yield Prediction is a deep learning project
designed to predict agricultural crop yield using
historical agricultural and weather information.

The project uses Machine Learning, Deep Learning,
and Explainable AI techniques.

## Technologies

- Python
- TensorFlow / Keras
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- SHAP
- Flask

## Dataset

Agricultural Crop Yield in Indian States Dataset.

Dataset features:

- Crop
- Crop Year
- Season
- State
- Area
- Production
- Annual Rainfall
- Fertilizer
- Pesticide
- Yield

## Installation

Create virtual environment:

python -m venv .venv

Activate:

.venv\Scripts\activate

Install dependencies:

pip install -r requirements.txt

## Dataset Inspection

Place the CSV file inside:

dataset/raw/crop_yield.csv

Execute:

python src/data_inspection.py

## Project Development

Phase 1: Dataset acquisition and inspection

Phase 2: Data cleaning and feature engineering

Phase 3: Exploratory data analysis

Phase 4: Machine Learning and Deep Learning

Phase 5: Model evaluation and explainability

Phase 6: Flask application development

Phase 7: Documentation and deployment

## Prediction Target

Crop Yield (tons per hectare).

## Disclaimer

Predictions are estimates for educational
and research purposes. Actual crop yield
depends on several environmental and
agricultural factors.
